# R Theory — Volume I · A Visual Rewrite

A book-by-book restructured rewrite of the *R Theory — Volume I* manuscript.
Each book leads with pictures and intuition (live Desmos graphs), then the
formal audit with proof statuses preserved.

## Read it

Open `index.html` in a browser, or start with a single book:

- [`book0/`](book0/) — Book 0: Source Boundary and the Orientation Question
- [`book1/`](book1/) — Book 1: Mathematical Constitution
- Books 2–6 — forthcoming

The graphs are live [Desmos](https://www.desmos.com) calculators (internet
required); if Desmos fails to load, static PNG fallbacks in each book's
`graphs/` folder are shown instead.

## Structure of each book

- **Part I — See it first.** Pictures and the intuition each one carries.
- **Part II — Then earn it.** The formal audit, section by section.
- **Part III — Certification.** What is established, and what is not.
- **Part IV — Close the book.** Ledgers, zero-counts, and the handoff.

## Status discipline

Every claim in the text carries its status: checked proof, completed symbolic
check, completed numerical check, standard imported theorem, manuscript
assertion, assumption/axiom, or incorrect/incomplete. Nothing is promoted
beyond what the mathematics supports.

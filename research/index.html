1. Critical path: double-angle → elliptic → conic

The active program follows one line of identities outward. The double-angle formulas generate an elliptic (rotation) flow; the elliptic flow is the rational parametrization of a conic; the conic carries the full operator set. Each step below is proved from the previous one.

Chain (all PROVED):

  1. Double angle. H(2x) = 4H(x)V(x), V(2x) = 4V(x)² − 1/2, where H(x) = sin(2x)/4 and V(x) = H′(x) = cos(2x)/2. The pair (H,V) traces the ellipse V² + 4H² = 1/4 — the projective image of the circle conic X² + Y² = Z².
  2. Elliptic flow. The Δ = −1 Riccati equations generate rotation flows; uniform circular motion on the transfer conic: (p′,q′) = (−q,p), speed √2, p″ + p = 0, λ″ + λ = 1/2.
  3. Conic. Möbius chart transitions are conic automorphisms; the transition group G = ⟨a,b⟩ ⊂ PGL(2,ℝ) is finite of order 8, isomorphic to D₄ (presentation ⟨a,b | a² = b² = (ab)⁴ = 1⟩). Transfer geometry is a conic with chordal parameter λ = (1−p)/2.
  4. Phase. The complex-pair phase has the closed form φ = arg(W/U) = 2·arctan p, with tan(φ/2) = p — the Weierstrass uniformization tying the phase to the transfer coordinate.
  5. Transverse / radial. The x-flow splits as rotation × scaling: 2∂_θ − cosh(ℓs)∂_{ℓs} + cosh(ℓc)∂_{ℓc}, with radial flow ℓs′ = −cosh(ℓs), ℓc′ = +cosh(ℓc).
  6. Spinor. Cl(1,1) ≅ M₂(ℝ) proved from scratch (γ¹ = σ₃, γ² = iσ₂); the adjoint double cover SL(2,ℝ) → SO⁺(2,1) with kernel {±I}; the conic action is literally this adjoint action.
